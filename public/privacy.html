Privacy Policy – porady-upload

Last updated: 27 September 2026

What this app is

porady-upload is a private tool used by a single person (its owner). It uploads meeting-notes documents from the owner's computer to the owner's own Google Drive. It is not offered to the public.

Google user data accessed

The app requests only the https://www.googleapis.com/auth/drive.file scope. This lets it create files in Google Drive and see or change only the files it created itself. It cannot see, read or change any other files in the user's Google Drive.

How the data is used

The app uses this access only to upload documents, convert them to Google Docs, and check whether a document it uploaded earlier already exists, so it can avoid duplicates.

Storage and sharing

The OAuth access token is stored only on the owner's computer. No Google user data is collected, sent to, stored on or shared with any server or third party. The app has no analytics, advertising or tracking.

Limited Use

porady-upload's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/connections.
